# Автопостер FunPay

**Панель:** https://mm88vin11.github.io/FunPay-Chat/ (открывается на любом устройстве)

Бот пишет ваше сообщение в общий чат каждой игры на funpay.com раз в `intervalMinutes` минут. Если ваше сообщение ещё среди 5 последних в чате, бот его пропускает и проверяет этот чат снова через интервал.

- Список игр бот берёт с главной страницы FunPay, так что новые игры подхватываются сами. Игры без чата он перепроверяет раз в сутки.
- Работает на GitHub Actions бесплатно и круглосуточно: каждый запуск идёт ~5,5 часа и сам запускает следующий. Расписание раз в 30 минут подстраховывает, если цепочка прервётся.
- Статус, счётчики и журнал бот публикует в ветку `status`, а панель (ветка `gh-pages`) их показывает.

## Ключ FunPay (обязательно)

1. На funpay.com в браузере: F12 → Application → Cookies → `https://funpay.com` → скопируйте значение `golden_key`.
2. Откройте https://github.com/mm88vin11/FunPay-Chat/settings/secrets/actions/new, в поле Name укажите `GOLDEN_KEY`, в поле Secret вставьте ключ.

Если нажать «Выйти» на сайте FunPay или сменить пароль, ключ сбросится. Тогда панель покажет «Нужен ключ», и ключ надо заменить.

## Настройки — config.json

Бот перечитывает файл каждую минуту, перезапуск не нужен.

| Поле | Значение |
|---|---|
| `enabled` | `false` — пауза |
| `message` | текст; `{game}` заменяется названием игры |
| `intervalMinutes` | как часто писать в каждый чат |
| `topN` | сколько последних сообщений проверять |
| `requestDelaySeconds` / `sendDelaySeconds` | паузы между запросами и после отправки |
| `includeGameIds` / `excludeGameIds` | писать только в эти игры / не писать в эти (id из `data-id` на главной FunPay) |
| `messageOverrides` | свой текст для игры: `{"41": "Куплю голду Dota 2"}` |

## Локальный запуск

```bash
GOLDEN_KEY=ваш_ключ node bot.mjs            # Node.js 20+
DRY_RUN=1 GOLDEN_KEY=ваш_ключ node bot.mjs  # без отправки
```

Частые одинаковые сообщения FunPay может посчитать спамом и выдать мут или бан.
