# FunPay Chat Bot

Бот раз в N минут пишет ваше сообщение в общий чат каждой игры на funpay.com.
Если ваше сообщение ещё среди 5 последних в чате, бот его пропускает и проверяет этот чат снова через N минут.

- Список игр бот берёт с главной страницы FunPay при каждом запуске, так что новые игры подхватываются сами.
- Общий чат у FunPay один на игру, и в разделе «Прочее» показывается тот же чат. Сейчас он есть примерно у 125 из ~890 игр. Игры без чата бот пропускает и перепроверяет раз в сутки.
- Работает на GitHub Actions бесплатно (репозиторий публичный). Сервер и ИИ не нужны.

## Настройка (один раз, ~3 минуты)

1. **Получите `golden_key`.** Войдите на funpay.com в браузере → F12 → Application (Хранилище) → Cookies → `https://funpay.com` → скопируйте значение `golden_key`.
2. **Добавьте секрет.** В репозитории: Settings → Secrets and variables → Actions → *New repository secret*. Имя `GOLDEN_KEY`, значение — ключ из шага 1.
3. **Задайте текст сообщения.** Там же откройте вкладку *Variables* → *New repository variable*:
   - `MESSAGE` — текст сообщения (можно в несколько строк);
   - `INTERVAL_MINUTES` — необязательно, по умолчанию 30.

   Вместо переменных можно отредактировать `config.json`.
4. **Запустите.** Actions → *FunPay bot* → *Run workflow*. Для пробы отметьте *Test mode*: бот всё проверит, но ничего не отправит. Дальше он запускается сам каждый час, а каждый запуск работает почти 6 часов, так что бот работает непрерывно.

Логи всех действий видны во вкладке Actions.

## config.json

| Поле | Значение |
|---|---|
| `message` | текст по умолчанию (переменная `MESSAGE` важнее) |
| `intervalMinutes` | N — как часто писать в каждый чат |
| `topN` | сколько последних сообщений проверять (5) |
| `requestDelaySeconds` / `sendDelaySeconds` | паузы между запросами и после отправки, чтобы FunPay не ограничил аккаунт |
| `includeGameIds` | если не пусто — писать только в эти игры (id из `data-id` на главной) |
| `excludeGameIds` | игры, в которые не писать |
| `messageOverrides` | свой текст для конкретной игры: `{"41": "Куплю голду Dota 2"}` |

## Запуск на своём компьютере или сервере

```bash
GOLDEN_KEY=ваш_ключ node bot.mjs            # нужен Node.js 20+
DRY_RUN=1 GOLDEN_KEY=ваш_ключ node bot.mjs  # тест без отправки
```

## Важно

- Частые одинаковые сообщения во всех чатах FunPay может посчитать спамом и выдать мут или бан. Не ставьте интервал слишком маленьким.
- `golden_key` даёт полный доступ к аккаунту. Храните его только в секретах и никому не передавайте.
- GitHub отключает расписание, если в публичном репозитории 60 дней не было коммитов. Тогда включите workflow заново во вкладке Actions или сделайте любой коммит.
